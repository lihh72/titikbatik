# Aset demo TitikBatik

Gambar motif/costume dan video disalin dari `automation/storage/output` proyek ini, untuk demo lokal. Nama, seed, tanggal, warna, dan deskripsi pada demo bersifat ilustratif; metadata tidak diklaim sebagai data katalog backend.

Foto editorial `batik-artisan-canting.jpg` dan `batik-malam-tools.jpg` berasal dari `web/public/editorial`; atribusi asli dipertahankan pada file `EDITORIAL-CREDITS.md` di folder ini. Logo berasal dari `web/public/logoo.png`.
